# 📄 Official Claim Approval Certificate
I have implemented the **Digital Approval Certificate** generation system.

## 🚀 How it Works
1.  **Approval:** When an Admin moves a claim to **"Approved"** status:
2.  **Download:** A new **"Download Certificate"** button appears next to the "Mark Completed" button.
3.  **Content:** The PDF contains:
    -   Official Header ("Government of India / State Dept").
    -   Claim Reference & Farmer Details.
    -   **Satellite Verified Loss Assessment**.
    -   **Total Approved Amount**.
    -   Digital Verification Stamp.

## 🔄 To Test
1.  Go to **Admin Claims** (`/admin/claims`).
2.  Select a claim and click **Approve** (if not already).
3.  Click the blue **"Download Certificate"** button.
4.  A professional PDF will check download! 📄✅

## 🚜 Farmer Access
Ideally, the Admin downloads and shares this PDF with the farmer via WhatsApp/Email. In future updates, we can add a "My Claims" dashboard for direct farmer access.
