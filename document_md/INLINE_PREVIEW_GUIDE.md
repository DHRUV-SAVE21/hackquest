# 🖼️ Improved Image Viewing
I have updated the Admin Panel to show **Inline Image Previews**.

## 🚀 The Fix
-   **Previously:** You had to click "View" which opened a new tab (sometimes failing with secure files).
-   **Now:** The Satellite Proof and other photos generally appear **directly in the popup window**.

## 🛠️ "Untitled" Issue
-   If you see "Untitled" or strange names, it might be from older test data.
-   New claims submitted from the **Satellite Monitor** will clearly show as **"Crop photo 1"**, **"Land document"**, etc.
-   Please **Submit a Fresh Claim** to verify the clean naming and image previews.

## 🔄 To Test
1.  Go to Admin Claims (`/admin/claims`).
2.  Open a **New** claim (Status: Submitted).
3.  Click **View**.
4.  Scroll down to Documents.
5.  You will see the **Satellite Map Image** directly on the screen! ✅
